(06) FAQ

Know it all.

Do I need a CA to use SimpleGST?

No. You can file on your own, and you can book a call with a CA any time you need help.

Can I file a nil return?

Yes. If you have nothing to report this month, use the nil return option.

What if I have no purchases yet?

Add sales first. Purchases can be added later before you file.
